# 设计系统 —— MyGo API v1.0.0

本文件是界面的**唯一权威规范**。新增功能、改样式、调布局之前先读它；实现与本文件冲突时，以 `src/style.css` 顶部令牌段为最高事实源，并在同一次改动里把本文件改回来。

```text
改 UI 的顺序：查本文件 → 只用既有令牌与原语 → 跑 npm run lint:ui → 浅色/深色各截一张图 → 提交
```

---

## 1 基调（不可协商）

| 维度 | 定调 |
| --- | --- |
| 气质 | 本地工具、高信息密度、低装饰噪音。像一个好用的编辑器，不像营销页 |
| 底色 | 中性冷灰（亮色偏冷白，暗色近黑偏蓝） |
| 强调色 | **只有一种**：靛蓝。第二强调色一律不批 |
| 圆角 | 小圆角、方硬感。不用大圆角卡片、不用胶囊包住整块区域 |
| 阴影 | 只用于「浮起」的元素（弹层、菜单、按钮轻投影），不用于分区 |
| 字体 | 界面用无衬线（Inter / 系统 UI 字体），数据用等宽（monospace）。正文 13px |
| 动效 | 只做「状态切换被看见」：≤ 180ms，缓出，无回弹、无位移表演 |
| 文案 | 全中文，动词开头，一句话说完 |

## 2 令牌三层与铁律

```text
全局物理值  ──►  别名令牌（--accent / --text-2 / --fs-md …）  ──►  组件规则（.btn / .kv-row …）
只在 :root 与主题块里出现        代码只允许引用这一层                组件内不得再写字面量
```

铁律（`npm run lint:ui` 会扫）：

1. **禁止裸色值**：`#hex`、`rgb()`、`hsl()` 只允许出现在 `:root` 与两个暗色块里。
2. **禁止裸字号**：不得写 `font-size: 12px`，只能写 `var(--fs-*)`。
3. **禁止裸圆角**：不得写 `border-radius: 6px`，只能写 `var(--radius-*)`（`50%` 除外）。
4. **禁止裸阴影**：只能写 `var(--shadow-1|2|3|btn)`。
5. 需要新颜色/新字号时：先判断现有令牌能否覆盖；覆盖不了才加，且必须**同时**在
   `:root`、`html[data-theme="dark"]`、`html[data-theme="auto"]`（`prefers-color-scheme: dark`）三处补齐，再登记到本文档。

### 3.4 阴影与动效

| 令牌 | 用途 |
| --- | --- |
| `--shadow-1` | 按钮、输入框、行块的轻投影 |
| `--shadow-2` | 悬浮卡片、引导页 logo |
| `--shadow-3` | 对话框、命令面板、下拉菜单这类「浮起」的层 |
| `--shadow-btn` | 主按钮专用（带内高光） |
| `--ring` / `--ring-bad` | 焦点环（3px 柔光）与错误焦点环，用 `box-shadow` 画，不额外占位 |
| `--shadow-tab-underline` | 页签激活下划线（内阴影，避免改变高 1px） |
| `--speed` | 140ms，所有 `transition` 的默认时长 |

具名动画只有三个，其余一律不许新增：

| 动画 | 时长 | 用途 |
| --- | --- | --- |
| `fade-in` | 120ms | 遮罩层淡入 |
| `pop-in` | 90ms / 180ms | 90ms 用于下拉菜单与通知；180ms 用于对话框、命令面板、引导卡片（`translateY(6px) scale(.985)` → 原位） |
| `spin` | 0.7s 循环 | 加载指示器（唯一允许的循环动画） |

新增动画必须同时改 `docs/设计系统.md` 本表与 `scripts/check-ui-tokens.mjs` 的 `ALLOWED_ANIMATION`，否则 `npm run lint:ui` 会报。**禁止**回弹、抖动、超过 180ms 的入场动画、循环装饰动画。

### 3.5 字体族

| 令牌 | 用途 |
| --- | --- |
| `--sans` | 全部界面文字（Inter → 系统 UI → Microsoft YaHei UI → PingFang SC） |
| `--mono` | URL、JSON、响应体、cURL、状态码、键值表的等宽内容 |

## 4 布局骨架

### 4.1 尺寸恒定值

| 区域 | 值 | 说明 |
| --- | --- | --- |
| 顶栏 `.topbar` | 高 46px，`padding: 0 10px 0 14px`，`gap: 10px` | 品牌、环境胶囊、右侧工具图标 |
| 状态栏 `.status-bar` | `padding: 7px 12px`，`gap: 10px` | 环境、集合/历史计数、快捷键提示 |
| 侧边栏 | 默认 288px，范围 208–520px | `DEFAULT_SIDEBAR_WIDTH`，拖拽调宽，双击分割条复位 |
| 响应区 | 默认 340px，范围 140–900px | `DEFAULT_RESPONSE_HEIGHT`，同上 |
| 请求区子页签行 | 高 34px | 查询参数/请求头/请求体/认证/选项 + 右侧环境胶囊 |
| 按钮 `.btn` | 高 30px，`padding: 0 11px`；`.small` 26px | 一屏只允许一个 `.primary` |
| 图标按钮 `.icon-btn` | 28×28；`.mini` 22×22 | 顶栏、行内操作 |
| 图标 `.ic` | 16×16；`.mini` 13×13；行内小图标 12×12 | 线性描边 |

### 4.2 栅格与间距

- 基准 4px；允许的间距值：**2 / 4 / 6 / 8 / 10 / 12 / 14 / 16 / 20 / 24 / 26**。
- 组件内间距（`padding` / `gap`）优先 4 / 6 / 8 / 10；区块之间用 12 / 16；对话框内边距 26。
- 分隔一律用 `1px solid var(--border)`；要更明显时用 `--border-strong`，不靠加粗或加阴影。
- 不做「卡片套卡片」；需要分组时用标题 + 1px 分隔线，而不是再加一层边框。

### 4.3 层级（z-index）

| 值 | 用途 |
| --- | --- |
| 1 | 粘性「新增标签页」按钮 |
| 5 | 拖拽分割条 |
| 20 | 顶栏 |
| 40 | 顶栏下拉菜单（环境菜单） |
| 100 | 对话框遮罩 `.backdrop` |
| 200 | 输入补全浮层 `.assist` |
| 300 | 应用内确认/输入框 `.prompt-backdrop` |
| 400 | 通知 `.toasts` |

新增浮层先看能否复用上表档位；不得出现 41、99 这类插空值。

## 5 组件原语（不得另起炉灶）

新增界面先在下表找可复用的，找不到再扩展原语，扩展后必须在本表登记。

| 原语 | 类名 | 变体 / 状态 | 约束 |
| --- | --- | --- | --- |
| 按钮 | `.btn` | `primary` / `ghost` / `danger` / `danger-solid` / `small` ；hover / active / disabled | 图标 + 文字间距 6px；禁止两行文案 |
| 图标按钮 | `.icon-btn` | 默认 28 / `mini` 22；hover 有底色 | 必须有 `title` 或 `aria-label` |
| 文字按钮 | `.link-btn` | 强调色文字，hover 出现底色 | 只用于行内轻量动作 |
| 输入框 | `.text-input` / `.search-input` / `.url-input` | default / focus / invalid / disabled | 高度 30px，字号 `--fs-md`；focus 用 `--accent-ring` |
| 字段容器 | `.field` + `.field-label` + `.field-hint` | 单列 / `form-grid` 双列 / `form-single` 整行 | 提示文字独占整行（`.field-hint{grid-column:1/-1}`） |
| 键值表 | `.kv-row` / `.kv-key` / `.kv-value` / `.kv-check` / `.kv-del` | 行 hover 显删除 | 勾选框 14×14，删除按钮绝对定位靠右 |
| 分段控件 | `.segmented` / `.segmented-item` | 选中 | 用于少量互斥视图切换（响应体/响应头） |
| 方法标签 | `.method-tag` + `.tone-*` | GET/POST/PUT/DELETE/其他 | 小写高度固定，等宽字体 |
| 状态徽标 | `.badge` / `.chip` / `.tone-ok/.tone-warn/.tone-bad/.tone-redirect` | 状态码、耗时、大小、类型 | 数字用等宽，单位附在数字后 |
| 页签 | `.tab` / `.tab-name` / `.tab-dirty` / `.tab-close` / `.tab-add` | active / hover / 脏标记 | 一张标签页只显示一个未命名状态 |
| 子页签 | `.subtab` | active（1px 下划线与强调色） | 最多 5 个，超出要考虑合并 |
| 树行 | `.tree-row` | hover / selected / 折叠箭头 | 缩进 12px/层，图标 16px |
| 历史行 | `.history-row` | hover / 状态色 | 两行布局：方法+地址+状态码 / 时间+耗时 |
| 下拉菜单 | `.env-menu` / `.palette` | 分组标签 / 项 hover / 选中打勾 | 圆角 `--radius`，`--shadow-3`，`animation: pop-in 90ms` |
| 对话框 | `.backdrop` + `.dialog` | 头部 / 正文 / 底部按钮区 | 圆角 `--radius-lg`，正文内边距 26，底部右对齐主次按钮 |
| 确认/输入框 | `.prompt-backdrop` | 同上 | 仅用于应用内二次确认与单行输入 |
| 通知 | `.toasts` / `.toast` | 成功 / 失败，2.5s 自动消失 | 右下角堆叠，最多 3 条 |
| 空状态 | `.sidebar-empty` / `.pane-empty` / `.response-empty` | 图标 + 一句话 + 可选操作 | 不写营销文案 |
| 代码视图 | `.code-view` / `.json-line` / `.json-value` / `.json-key` | 折叠 / hover 行 | 等宽字体、行高 1.6、缩进 2 空格 |

**状态矩阵底线**：凡是可点的原语，至少实现 default / hover / active / focus-visible / disabled；有异步的补 loading；有校验的补 error。缺状态的组件不许提交。

## 6 图标

- 唯一来源：`src/ui/dom.ts` 的 `icons`（24×24 viewBox，`stroke: currentColor`，`stroke-width: 1.7`，圆角端点）。
- 尺寸只允许 16 / 13 / 12 三档（由 `.ic` 与上下文类控制），不得用 `width: 14px` 这类散值。
- 一个动作一个图标；同类动作复用同一图标（删除永远用 `close/trash`，新增永远用 `plus`）。
- **禁止**：引入图标库、使用 emoji 当图标、使用彩色/多色图标、用图片代替图标。

## 7 文案规范

- 全中文；专有名词（GET、JSON、cURL、SQLite、Cookie、Bearer、Basic、API Key、URL）保留原文。
- 按钮用动词或动宾短语：`发送`、`保存`、`新建集合`、`导入 cURL`、`清空历史`。不写「确定/OK」以外的英文。
- 对话框标题写对象不写动作：`保存请求`、`环境变量 · 当前：固定环境`。
- 错误提示 = 现象 + 下一步：`域名解析失败：请检查地址拼写或网络连接`，换行补一句「检查地址、端口、服务是否启动，以及系统代理是否拦截了该地址」。
- 空状态 = 说明 + 怎么做：`还没有响应 / 按 Ctrl+Enter 或点「发送」开始第一次请求。`
- 统一术语表（不得混用同义词）：

| 概念 | 唯一说法 | 不要写 |
| --- | --- | --- |
| 一次 HTTP 调用 | 请求 | 接口调用、API 调用 |
| 返回内容 | 响应 / 响应体 / 响应头 | 返回结果、response |
| 请求集合 | 集合 | 项目、分组、Collection |
| 集合内的分组 | 文件夹 | 目录、子集合 |
| 变量集合 | 环境 | 配置文件、Profile |
| 顶部打开的编辑器 | 标签页 | 窗口、Tab |
| 请求记录 | 历史 | 记录、日志 |

- 不用感叹号、不用「哦/啦/呢」、不写「请稍候…」这类空话（进度用真实状态文案）。

## 8 禁用清单（红线）

1. 新增第二种强调色，或把状态色（绿/橙/红/紫）当装饰色用。
2. 在组件里写裸色值 / 裸字号 / 裸圆角 / 裸阴影（`npm run lint:ui` 会拦）。
3. 引入 UI 组件库、CSS 框架、图标库、Web 字体。
4. 圆角、字号跑出本文件的档位表（新增档位要先改本文件）。
5. 大圆角卡片、玻璃拟态、大面积渐变、发光边框、拟物阴影。
6. 入场动画超过 180ms、回弹、抖动、无限循环动画（加载 spinner 除外）。
7. 只靠颜色表达状态（必须有文字或图标）。
8. 用 emoji、彩色图标、位图当图标。
9. 一屏出现两个 `.primary` 按钮。
10. 新增浮层用插空 z-index。
11. 改既有原语的高度/内边距/圆角却不更新本文件。
12. 只验证浅色主题就提交（暗色必须一起看）。

## 10 变更流程（改令牌 = 三处同步 + 全库替换）

```text
1. 改本文件（先定语义与用途）
2. 改 src/style.css：:root / html[data-theme="dark"] / html[data-theme="auto"] 三块
3. 全库替换引用（grep 旧令牌名），跑 npm run lint:ui 确认无漏
4. npm run e2e 截图核对浅色与深色
5. 一个逻辑改动一个提交，提交信息写清「令牌变更 + 影响范围」
```

破坏性令牌变更（改名、删档位）等同接口变更：先在本文档标注替换关系，再一次性全库替换，不留新旧两套。
